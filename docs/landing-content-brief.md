## 6. Портрет автора *(обязательно — блок «Обо мне + награды»)*

> Это не декоративный элемент: крупное фото рядом с текстом и грамотами — главный способ «познакомить» заказчика с человеком, который будет вести проект. Hero-фото показывает работу; этот портрет — **лицо** руководителя.

| Требование | Комментарий |
|------------|-------------|
| Приоритет | 🔴 Обязательно для MVP |
| Формат | Деловой, в рабочей одежде, спокойный открытый взгляд |
| Фон | Законченный объект или нейтральный интерьер |
| Кадр | По пояс или по грудь; вертикальная ориентация предпочтительна |
| Разрешение | Мин. 1200 px по короткой стороне |
| Избегать | Постановочный «художник с краской на лице», групповые фото |
| Файл | `author.jpg` |
| Статус | ☐ загружено |
