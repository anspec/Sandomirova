# Концепция лэндинга: Тамара Владимировна Сандомирова

> Художник-монументалист, руководитель проектов монументально-декоративных решений  
> Формат: одностраничный сайт-визитка (one-page)  
> Версия документа: MVP-концепция

---

## 1. Стратегия и цели

### Задачи лэндинга (в порядке приоритета)

| № | Задача | Как решается на странице |
|---|--------|--------------------------|
| 1 | **Быстро подтвердить профессионализм** | Избранное портфолио (6–8 работ), награды, цифры опыта |
| 2 | **Снять главное возражение:** «Будет ли порядок в процессах?» | Блок «Полный цикл под одной ответственностью» + этапы работы в 4 шага |
| 3 | **Персональное доверие** | Крупное фото автора в блоке «Обо мне» — лицо человека, с которым заключат договор |
| 4 | **Максимально короткий путь к разговору** | Одна CTA-кнопка на экране, форма из 4 полей, обещание ответа за 1 рабочий день |

### Целевая аудитория

- **B2B:** девелоперы, рестораторы, владельцы коммерческих пространств, архитекторы и дизайнеры интерьеров (как партнёры и как заказчики)
- **B2C:** владельцы частных домов и квартир с архитектурными задачами (лестницы, купола, камины, зоны приёма гостей)

### Фильтр аудитории

Страница **отсекает** запросы на «картины маслом на холсте» и **привлекает** клиентов с задачами интеграции искусства в архитектуру — через формулировки «монументально-декоративные решения», «общественные и частные пространства», перечень техник.

### Ключевое позиционирование

> Не «художник-одиночка», а **руководитель проекта** — единое окно ответственности от эскиза до приёмки.

## 2. Информационная архитектура (макет страницы)

Страница укладывается в **5–6 экранов** вертикального скролла (~15–25 секунд чтения). Одна главная CTA «Обсудить проект» повторяется в шапке и в финальном блоке.

```
┌─────────────────────────────────────────────────────────────┐
│  HEADER (sticky)                                            │
│  [Подпись / логотип]     Портфолио  Процесс  Обо мне  [CTA] │
├─────────────────────────────────────────────────────────────┤
│  ① HERO — первый экран                                      │
│  [Фото: фрагмент работы / процесс]                          │
│  Заголовок + подзаголовок + кнопка «Обсудить проект»        │
├─────────────────────────────────────────────────────────────┤
│  ② УСЛУГИ — что создаю (сетка 2×3 или 3×2)                  │
│  Роспись | Мозаика | Витраж | Коллекции | Световые композ.  │
├─────────────────────────────────────────────────────────────┤
│  ③ ПРОЦЕСС — снятие возражения «будет ли порядок?»          │
│  4 этапа в линию / 3 тезиса + мини-timeline                 │
├─────────────────────────────────────────────────────────────┤
│  ④ ПОРТФОЛИО — доказательство опыта (6–8 фото)              │
│  Сетка 3 колонки → pop-up при клике                         │
├─────────────────────────────────────────────────────────────┤
│  ⑤ ОБО МНЕ + НАГРАДЫ — доверие и социальное доказательство  │
│  [Крупное фото автора]  |  Имя + текст «обо мне»             │
│  ─────────────────────────────────────────────────────────  │
│  Лента наград / грамот (под фото и текстом)                 │
├─────────────────────────────────────────────────────────────┤
│  ⑥ ФОРМА ЗАЯВКИ — финальный CTA                             │
│  Имя | Телефон | Email | Описание задачи + прикрепление файлов │
├─────────────────────────────────────────────────────────────┤
│  FOOTER — телефон, email, мессенджер, соцсети / профили     │
└─────────────────────────────────────────────────────────────┘
```

### Навигация (header)

| Пункт меню | Якорь | Зачем |
|------------|-------|-------|
| Портфолио | `#portfolio` | Быстрый переход к доказательствам |
| Процесс | `#process` | Ответ на возражение о хаосе |
| Обо мне | `#about` | Личное доверие + награды |
| **Обсудить проект** (кнопка) | `#contact` | Основной CTA, контрастный цвет |

## 3. Контент блоков (готовые тексты для MVP)

### ① Hero — первый экран

**Визуал:** одна сильная статичная фотография — крупный план рук в работе, фрагмент мозаики с фактурой или готовая световая композиция в интерьере. Без видеофона (скорость загрузки, фокус на тексте).

**Заголовок (H1):**
```
Монументально-декоративные решения для общественных и частных пространств
```

**Подзаголовок:**
```
Тамара Владимировна Сандомирова — художник-монументалист, руководитель проектов
```

**Строка-уточнение (опционально, под подзаголовком):**
```
Росписи · мозаики · витражи · авторские коллекции · объёмно-пространственные композиции со светом
```

**Кнопка:** `Обсудить проект` → плавный скролл к форме

---

### ② Услуги — продуктовая матрица

Формат: **сетка карточек** (5 направлений). Под каждым — одно предложение о задаче, которую решает техника.

| Направление | Текст под карточкой (1 строка) |
|-------------|--------------------------------|
| **Роспись** | Живопись на стенах, потолках и сложных архитектурных поверхностях |
| **Мозаика** | Долговечные фактурные панно из смальты, камня, стекла |
| **Витраж** | Световые акценты и зонирование через авторское стекло |
| **Авторские коллекции** | Серии декоративных элементов для единого стиля пространства |
| **Объёмно-пространственные композиции со светом** | Арт-объекты, интегрированные в архитектуру и освещение |

*Объём текста блока: ~80–120 слов суммарно.*

---

### ③ Процесс — закрытие возражения «будет ли порядок?**

**Заголовок блока:**
```
Полный цикл — под одной ответственностью
```

**Вводный абзац (2–3 предложения):**
```
Как руководитель проекта я отвечаю за каждый этап: концепцию, подбор и исполнение в материале, координацию исполнителей, контроль сроков и приёмку результата. Вы получаете предсказуемый результат в согласованные по каждому этапу сроки — без потери контроля над бюджетом.
```

**Три тезиса (упрощённая версия — для быстрого сканирования):**

1. **Концепция** — погружение в архитектуру пространства, эскиз и согласование идеи  
2. **Материал и команда** — подбор долговечных материалов, координация узкопрофильных исполнителей и смежников  
3. **Сроки и приёмка** — контроль графика, прозрачная отчётность, финальная приёмка объекта  

**Альтернатива (4 шага timeline — если нужна чуть более «архитектурная» подача):**

| Этап | Заголовок | Описание |
|------|-----------|----------|
| 1 | Идея и концепция | Эскиз, мудборд, привязка к архитектуре |
| 2 | Материал | Образцы фактур, согласование бюджета |
| 3 | Исполнение | Координация мастеров, строителей, электриков |
| 4 | Приёмка | Контроль качества, сдача объекта в срок |

*Визуал этапов (по 1 фото на этап): эскиз на планшете → образцы материалов → команда за работой → готовый интерьер.*

*Объём текста блока: ~120–180 слов.*

---

### ④ Портфолио — главное доказательство профессионализма

**Заголовок:** `Избранные работы`

**Формат MVP:**
- Сетка **6–8 фотографий** (3 колонки на десктопе, 2 на планшете, 1 на мобильном)
- Под каждым фото: **название объекта + город** (без длинных описаний)
- Клик → **pop-up** с увеличенным фото + 2–3 строки: техника, площадь, год
- Отдельные страницы кейсов — **не в MVP**, добавить на этапе v2

**Рекомендуемый состав избранного (показать диапазон):**

| № | Тип объекта | Зачем в подборке |
|---|-------------|------------------|
| 1 | Частный интерьер (дом / квартира) | B2C-аудитория узнаёт себя |
| 2 | Ресторан / кафе | Коммерческий сегмент |
| 3 | Офис / бизнес-центр | B2B, масштаб |
| 4 | Объект со сложным светом | Демонстрация уникальной компетенции |
| 5 | Мозаика (крупный фрагмент) | Тактильность, фактура |
| 6 | Витраж / роспись | Широта техник |

**Подпись под блоком (микро-CTA):**
```
Есть похожая задача? Расскажите о ней — подготовлю предложение.
```
→ ссылка на форму

### ⑤ Обо мне + Награды

> **Роль блока:** после портфолио и процесса заказчик уже убедился в компетенции — здесь он «знакомится» с человеком, который будет вести проект. Личное фото снимает абстрактность бренда и переводит доверие с «студии» на конкретного руководителя.

**Макет (desktop):** двухколоночный — **фото слева (~40% ширины)**, текст справа; на мобильном фото **над** текстом, на всю ширину.

```
┌──────────────────────┬────────────────────────────────────┐
│                      │  Обо мне                           │
│   [Фото автора]      │  Тамара Владимировна Сандомирова   │
│   крупный портрет    │                                    │
│                      │  Текст 3–4 предложения…           │
└──────────────────────┴────────────────────────────────────┘
│  Признание профессионального сообщества                   │
│  [грамота] [грамота] [грамота] …                          │
└───────────────────────────────────────────────────────────┘
```

**Заголовок:** `Обо мне`

**Подпись под заголовком (имя крупнее текста):**
```
Тамара Владимировна Сандомирова
```

**Текст (3–4 предложения):**
```
Я отвечаю за каждый этап лично — от первого эскиза до финальной приёмки. Это гарантирует целостность замысла и предсказуемый результат для заказчика. Работаю с общественными и частными пространствами: от локальных акцентов до масштабных монументальных программ.
```

**Фото автора — обязательный элемент блока:**

| Параметр | Рекомендация |
|----------|--------------|
| **Размер в макете** | Крупный портрет, не миниатюра — мин. 320×400 px в вёрстке, исходник от 1200 px |
| **Характер снимка** | Деловой, спокойный, открытый взгляд; рабочая одежда |
| **Фон** | Законченный объект или нейтральный интерьер — связь с профессией |
| **Избегать** | Постановочный «художник с краской на лице», групповые фото, сильные фильтры |
| **Зачем** | Заказчик B2B/B2C перед заявкой хочет видеть, *с кем* будет общаться; фото рядом с наградами усиливает связку «живой эксперт + признание профессионалов» |

*Hero показывает **работу**; блок «Обо мне» показывает **автора** — два разных фото, оба нужны.*

#### Подблок: Награды, грамоты, поощрения

> *В исходных материалах раздел отсутствовал — включён в макет как блок социального доказательства.*

**Заголовок:** `Признание профессионального сообщества`

**Формат MVP:** горизонтальная лента или сетка 3×2:
- скан/фото грамоты или диплома (уменьшенное превью)
- подпись: название награды, год, организация-учредитель

**Пример структуры карточки награды (заполнить реальными данными):**

| Поле | Пример заполнения |
|------|-------------------|
| Название | Диплом участника выставки «…» |

**Если наград мало (1–2):** дополнить блок цифрами опыта:
- X+ реализованных объектов
- X лет в монументальном искусстве
- X городов / регионов

*Объём текста блока «Обо мне»: ~60–80 слов + 3–6 карточек наград.*

## 4. Визуальные и технические рекомендации (MVP)

### Дизайн-прinciples

| Аспект | Рекомендация для MVP |
|--------|----------------------|
| **Контраст** | Масштаб и тактильность работ + строгая сетка подачи информации |
| **Типографика** | Один гротеск (Inter / Montserrat) — различие через размер и начертание |
| **Цвета** | Белый фон, тёмно-серый текст, один акцент (терракота / индиго / охра) для кнопок |
| **Эффекты** | Только fade-in при скролле. Без параллакса, видеофона, сложной анимации |
| **Адаптив** | Фото кадрируются с сохранением фактуры на мобильном (крупный план, не «общий план стены») |

### Производительность

- Hero-изображение: WebP, ≤ 200 КБ
- Портфолио: lazy-load, ≤ 150 КБ на превью
- Целевое время загрузки: < 3 сек на 4G

## 8. Метрики успеха MVP

| Метрика | Целевое значение | Как измерять |
|---------|------------------|--------------|
| Конверсия в заявку | 2–5% посетителей | Яндекс.Метрика / GA4, цель «Отправка формы» |
| Время на странице | > 45 сек | Метрика вовлечённости |
| Скролл до портфолио | > 60% | Карта скроллинга |
| Скролл до формы | > 30% | Карта скроллинга |
| Скорость ответа на заявку | ≤ 1 рабочий день | Внутренний KPI |
